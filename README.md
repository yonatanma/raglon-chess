# שחמט עם רגלון

לומדים שחמט צעד אחר צעד: שיעורים מונפשים בעברית ואתגרים קטנים, לילדים בני 5–7.

**משחקים כאן:** https://yonatanma.github.io/raglon-chess/

## מה יש באפליקציה
- 9 נושאים: הלוח, צריח, רץ, מלכה, מלך, פרש, רגלי, אכילה, משבצות שמורות. 36 אתגרים.
- רגלון מסביר בקול (קול עברי של המכשיר) ובכתוביות.
- עד 6 ילדים, עם התקדמות נפרדת לכל אחד.
- אזור הורים: לוחצים ומחזיקים את הכפתור כדי להיכנס.
- התקנה במסך הבית ועבודה בלי אינטרנט.

## מבנה
- `index.html`: המסכים
- `js/engine.js`: חוקי התנועה ופותר שמחשב את מספר המהלכים המינימלי
- `js/content.js`: השיעורים והאתגרים
- `js/app.js`: הלוח, האנימציות, הנוף, רגלון
- `js/shell.js`: פרופילים, אזור הורים, התקנה, עבודה בלי אינטרנט
- `sw.js`: שמירת הקבצים לעבודה בלי אינטרנט

## עדכון גרסה
אחרי כל שינוי, להעלות את `VERSION` ב־`sw.js` ואת `APP_VERSION` ב־`js/shell.js`. בפתיחה הבאה תופיע הודעה "יש גרסה חדשה".
